# Roadmap / 路线图

- [ ] Chinese/English UI switch / 中英文界面切换
- [ ] First-run privacy explanation / 首次运行隐私说明

- [ ] Code-signed installer / 代码签名安装包
- [ ] Automatic update channel with explicit consent / 经用户明确同意的自动更新通道

Feature proposals are tracked in GitHub Issues. / 功能建议通过 GitHub Issues 跟踪。
